# 📱 Programación Multimedia y Dispositivos Móviles (PMDM) - DAM

![DAM](https://img.shields.io/badge/Ciclo-DAM-blue?style=flat-square)
![Comunitat Valenciana](https://img.shields.io/badge/Currículo-Comunitat_Valenciana-orange?style=flat-square)

Repositorio de proyectos, prácticas y apuntes del módulo **Programación Multimedia y Dispositivos Móviles (PMDM)**, correspondiente al 2º curso del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Multiplataforma (DAM)**. 

Los contenidos y resultados de aprendizaje de este repositorio están estructurados de acuerdo con el currículo oficial establecido para la **Comunitat Valenciana** (Decreto 63/2012 del Consell, que desarrolla el Real Decreto 450/2010 a nivel autonómico).

---

## 📂 Estructura del Repositorio

El repositorio está organizado para abarcar las unidades de trabajo del currículo de la Generalitat Valenciana:

*   📁 `UD01_Entorno_Desarrollo/` - Introducción a Android, SDK, y ciclo de vida de las aplicaciones (Activities).
*   📁 `UD02_Interfaces_Usuario/` - Layouts, Vistas (Views), RecyclerView, Fragments y Navigation.
*   📁 `UD03_Persistencia_Datos/` - SharedPreferences, ficheros y bases de datos locales (SQLite / Room).
*   📁 `UD04_Hilos_y_Comunicaciones/` - Concurrencia (Corrutinas), consumo de APIs REST y librerías de red (Retrofit).
*   📁 `UD05_Hardware_Sensores/` - Localización (GPS), cámara, Bluetooth y sensores del dispositivo.
*   📁 `UD06_Multimedia/` - Reproducción y grabación de audio y vídeo, animaciones.
*   📁 `UD07_Publicacion/` - Firma de aplicaciones (Keystore), APK/AAB y subida a Google Play Store.

---

## 🛠️ Tecnologías y Herramientas

A lo largo de las distintas unidades se utilizarán diversas tecnologías estándar en la industria del desarrollo móvil (principalmente enfocado en Android):

*   **Lenguajes:** Kotlin (recomendado/oficial), Java.
*   **Frameworks y Librerías:** Android SDK, Room (ORM), Retrofit, Glide/Picasso, Jetpack Compose.
*   **Arquitecturas:** MVVM (Model-View-ViewModel).
*   **Entornos de Desarrollo (IDEs):** Android Studio.
*   **Servicios Cloud:** Firebase (Autenticación, Firestore, Push Notifications).
